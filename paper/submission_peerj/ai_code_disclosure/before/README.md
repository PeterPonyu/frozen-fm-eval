# Before: Author Drafts

These six flat scripts are curated author-draft versions of the selected evaluation code. They retain the dense research-script structure, duplicated metric and JSON helpers, fixed seeds, and scientific procedures of the released analyses. Machine-local dataset paths were replaced with `DATA_ROOT` or portable relative paths.

This directory is a representative reconstruction for disclosure; it is not claimed to be a preserved full-repository pre-AI tag. Set `DATA_ROOT` and run from the project root with the expected `expand_results/`, `raw_pulls/`, and `scatac_results/` inputs.
