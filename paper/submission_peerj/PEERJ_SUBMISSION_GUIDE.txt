TEMPLATE / CLASS
- Use the PeerJ Overleaf template class: wlpeerj.cls (STOCK — do NOT edit it).
  PeerJ's online all-TeX system supplies this class server-side.
- Build with pdflatex, NOT lualatex (wlpeerj is a pdflatex class: Times/mathptmx +
  inputenc). lualatex only substitutes fonts with "Font shape TU/... undefined".
  Pin it locally with .latexmkrc:  $pdf_mode = 1;
- Turn ON line numbers (PeerJ REQUIRES them):
      \documentclass[fleqn,10pt,lineno]{wlpeerj}
- Title / author / \affil / \keywords / \begin{abstract} all go in the PREAMBLE
  (before \begin{document}); call \maketitle after \begin{document}.
- Sections are UNNUMBERED: \setcounter{secnumdepth}{0}

TITLE
- Sentence case, NOT Title Case (PeerJ flags "too many capitalized words").
  Only the first word + proper nouns/acronyms are capitalised.

ABSTRACT
- Structured with bold run-in labels: Background. / Methods. / Results. / Conclusions.
  (PeerJ house style; most PeerJ CS papers use it). Pure regrouping — no number changes.
- Define every acronym at first use (e.g. "expected calibration error (ECE)").

BIBLIOGRAPHY  (the biggest gotcha — get this right or citations break on their server)
- PeerJ's stock wlpeerj.cls hard-codes \bibliographystyle{apalike} (author-year,
  ALPHABETICAL) and the system BLOCKS .cls and .bbl uploads. So:
    * You CANNOT override the style with your own \bibliographystyle (a 2nd one clashes:
      BibTeX "Illegal, another \bibstyle" -> all citations break).
    * apalike alone gives an alphabetical list with non-sequential in-text numbers.
- SOLUTION: EMBED the reference list inline as a `thebibliography` block, numbered by
  first citation (generate it once with \bibliographystyle{unsrtnat}, then paste the .bbl
  in place of \bibliography{references}). Keep \setcitestyle{numbers,square,comma,sort&compress}
  for numeric [n]. With NO \bibliography/\bibliographystyle call, BibTeX never runs on
  their server (no clash), and citations are sequential [1],[2],... by appearance.
- references.bib is then only the source; it is NOT needed for the compile.

FIGURES
- PeerJ needs each figure as its OWN hi-res file (a TikZ .tex is source, not a figure).
- Use VECTOR PDF (or EPS). NOT JPEG (lossy — blurs line-art/text). NOT .tex.
- Name them Figure1.pdf ... FigureN.pdf in ORDER OF APPEARANCE. Paste each caption.
- Multi-panel schematic (Figure 1 here = 2 panels): when exporting standalone, resize
  BOTH panels to a COMMON width (\resizebox{\figw}{!}{...} in a fixed-width minipage),
  NOT a centering tabular at natural widths, or the panel tags (A/B) misalign.
- Submission manuscript uses \includegraphics{FigureN.pdf} (not \input TikZ): faster/
  safer on their compiler and it doesn't ship the per-point data coordinates in the .tex.

FLAT SOURCE
- PeerJ compiles all uploaded files in ONE flat directory (NO subfolders). Keep every
  file flat and reference it with no path prefix (\includegraphics{Figure1.pdf}, not
  figs/Figure1.pdf).

-------------------------------------------------------------------- [ TITLE ]
Auditing frozen foundation-model embeddings: a leakage-controlled, calibration-aware evaluation protocol stress-tested on single-cell genomics

------------------------------------------------------------- [ SHORT TITLE ]  (<=40 chars)
Auditing frozen FM embeddings

----------------------------------------------------------------- [ ABSTRACT ]  (plain text, ~1842 chars)
Background. Evaluating frozen foundation-model (FM) embeddings is unreliable when the scoring metrics are entangled with the methods they rank, when tokenizer coverage is confounded with representation quality, and when the exchangeability that underwrites uncertainty guarantees is broken by distribution shift. Methods. We present a reusable, deterministic evaluation protocol for pretrained representations under distribution shift, built on four domain-general moves: every agreement metric is paired with a non-linear (kNN) probe and a reference-free structure metric to expose label circularity; tokenizer/vocabulary coverage is treated as a measured variable rather than a fixed assumption; parity is argued with an equivalence test (TOST) rather than an absent p-value; and reliability is audited with split-conformal coverage, expected calibration error (ECE), and selective abstention. The protocol's signature move replaces binary leaderboard verdicts with a dose-response analysis that places the criticized method class on the curve, converting a rank into a manipulable, causal mechanism. We stress-test it on single-cell genomics, a demanding regime of batch/donor shift, circular annotation, and cross-species tokenizer mismatch, across four modalities, up to 24 leakage-controlled atlases, and five FM families. Results. Three findings follow: zero-shot single-cell FMs neither beat nor trail simple baselines on matched vocabularies; the much-warned cross-batch calibration collapse is a general exchangeability failure of the data regime, not an FM defect; and which side "wins" is set by task and evaluation metric, not model scale or architecture. Conclusions. All findings are scoped to the zero-shot, frozen-embedding regime on coarse human cell types; fine-tuning and few-shot transfer are untested and can reverse them.
