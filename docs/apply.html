Frozen-FM-Eval — Apply

RECIPEAPPLY

Five-step recipe for a new frozen-embedding setting

  1. Name the label-generating process. If ground truth is derived in a space a baseline occupies, add the non-linear probe and a reference-free structure metric.
  2. Measure the tokenizer or preprocessing coverage that varies across datasets and report quality against it.
  3. Pre-declare an equivalence margin and use TOST instead of reading equivalence off a non-significant test.
  4. Pick the deployment shift axis and report conformal coverage, ECE, and selective abstention under that shift.
  5. For every rank you are tempted to report, build a dose–response on the manipulable driver and place the criticized method on the curve.

The deliverable is the audit, not the verdict: a frozen embedding is characterised by where on each curve it sits and why.
